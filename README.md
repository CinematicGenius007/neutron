# Project Neutron

Neutron is a personal, self-hostable, zero-knowledge secrets manager with a
later email-alias and encrypted-mail subsystem.

The project is currently in planning Stage 0. No production implementation or
cryptographic format has been finalized, and real credentials must not be
stored in Neutron yet.
